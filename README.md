# Pinshot（工作名，可随时改名）

Setuna 式**截图贴图工具**，附文字提取（OCR）与翻译。贴图即产品本体：
无主窗口，启动后驻留系统托盘，按下热键框选屏幕，截图原位钉在桌面上。

> 贴图交互（置顶、缩放、双击收纳、显隐全部等）设计参考 [Setuna2](https://github.com/tylearymf/Setuna2)（MIT），
> 为独立实现的 WPF 版本；文字提取默认使用 PaddleOCR 本地离线引擎（模型内嵌，无需安装）。

## 快捷操作

| 操作 | 功能 |
| --- | --- |
| **Alt+Shift+P** | 框选区域 → 原位生成置顶贴图 |
| 左键拖动 | 移动贴图（拖动期间保持半透明，Setuna 行为） |
| 滚轮 / Ctrl+滚轮 | 以光标为锚点缩放 / 调节透明度 |
| **双击** | 收纳为 60×60 小图（再双击或 Enter 还原） |
| 右键 | Setuna 式菜单：提取文字、翻译、复制、剪切、粘贴、另存为、旋转90度、垂直/水平翻转、收缩、修剪、画笔标注、缩放（50%~150%）、透明度（10%~100%）、边框（无边框/单色/立体）、关闭、关闭所有贴图 |
| Ctrl+R | 旋转 90° |
| Esc / Enter | 关闭贴图 / 从收纳态还原（裁剪模式下 Esc 取消、Enter 应用） |
| 方向键（Shift 加速）/ + − | 微移 / 中心缩放 |
| **Alt+Shift+H** | 隐藏 / 显示所有贴图 |
| 单击 / 双击托盘图标 | 激活（置顶）所有贴图 |
| 拖放图片/文件/网页图片到贴图上 | 创建新贴图（支持 PNG/JPEG/BMP/GIF 动画/ICO/TIFF/WebP/PSD/TGA/SVG） |

**图片标注**：右键 → 图片标注（画笔 / 文本 / 马赛克），进入微信截图式工具条——工具切换、粗细（细/中/粗）、8 种颜色、**撤回**（Ctrl+Z 逐步撤销）、**退出**（放弃全部修改）、**完成**（Enter 应用全部修改）。
**修剪模式**：右键 → 修剪，拖出选区后 Enter 应用、Esc 取消。
**翻译**：默认免费接口链（有道 → MyMemory → Google，自动回退，无需配置开箱即用），也可切换 OpenAI 兼容接口 / DeepL / 百度翻译 / 自定义接口。
**提取文字**：PaddleOCR 本地离线 OCR（模型内嵌，离线可用，小图自动放大提升识别率）。
设置窗口为 Setuna 式左侧分组导航：常规设置 / 截图设置 / 截图右键菜单 / 翻译与提取文字 / 系统托盘菜单。

新建截图时已有贴图会被自动遮蔽（DWM cloak），不会截进新图；支持多显示器与不同 DPI。

## 文字提取与翻译

- **提取文字**：默认使用 **PaddleOCR 本地引擎**（离线免费，中文/数字/英文识别率高；
  短边 <1000 的截图自动放大 2~3 倍后再识别，编辑器标签/菜单等密集小字丢字符明显减少），
  不可用时自动回退 Windows 系统 OCR；识别语言支持 **中/英/日/韩/俄** 五种
  （Windows OCR 语言包由应用启动时自动批量装齐——单次 UAC，设置中五种语言直接可选，无手动安装入口）。
- **翻译（图上原位）**：贴图 → 右键“翻译”，识别文字块后逐块翻译，译文按原文位置直接覆盖在图片上；
  翻译期间贴图上显示旋转 loading 遮罩（不挡拖拽/右键）；字号按本行行高适配，
  覆盖块**锁定原文字行框**（不叠加、不挤压相邻行），且**随贴图缩放同步缩放**；失败行自动串行补译一轮；
  原文已是目标语言的行原样覆盖，不误判失败。
- **命令/代码逐词对照**：检测到命令行/代码/URL（或混排行里整段翻不出的片段）时，
  自动提取其中的英文单词（驼峰命名自动拆词，如 ApplicationService→Application/Service）逐个查词典，
  生成「词=译」对照表作为译文；命令本身不改写，查不到的专有标识符保留原样。
- **对照翻译窗口**：与提取文字窗口同款结构——上半部分为提取出的原文，分隔线下方为译文；
  设置中可勾选 **显示原文 / 显示译文** 自由切换显示内容（都关时按都开处理）。
  默认使用免费接口链（**有道 → MyMemory → Google** 自动回退），**无需任何配置**；
  也可在设置中改用 **OpenAI 兼容接口**（OpenAI / 智谱 GLM / DeepSeek / Ollama）、**DeepL** 或 **百度翻译**。

配置保存在 `%APPDATA%\Pinshot\config.json`，也可通过 托盘 → 设置 修改，保存后热键即时生效。

## 排查

- 崩溃日志：`%APPDATA%\Pinshot\crash.log`（启动时已挂全局异常处理，托盘应用不会静默闪退；图上翻译失败会连同完整堆栈落盘，便于定位）。
- 无交互自检：`Pinshot.exe --selftest` 依次验证「单键热键」「OCR」「翻译链路（含中英混合分段）」
  「截图取消」「框选建贴图」「图上翻译（含大图连翻两次回归）」，逐个创建所有窗口并留存视觉截图，
  结果写入 crash.log，用于在无人值守/无鼠标环境下复现问题。

## 分发

发给别人只需 **`publish\Pinshot.exe` 一个文件**（自包含：.NET 运行时、PaddleOCR 模型、
native 依赖全部内嵌，首次启动自动释放到本地）。重新生成发布版：

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true ^
  -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

发布后若出现 `publish\inference` 文件夹可直接删除（模型已内嵌，运行时会按需重建）。
注意把 exe 放在**有写入权限的目录**（首次启动会在 exe 旁边释放模型，并在 `%APPDATA%\Pinshot` 写配置），
不要直接放 Program Files 这类受保护目录。

## 构建

需要 .NET 10 SDK（Windows）：

```
dotnet build -c Release
```

## 项目结构

```
App.xaml.cs                 启动：单实例、托盘、全局热键、截图入口、OCR 语言包批量安装
Core/Config.cs              配置（JSON 持久化）
Core/PinManager.cs          贴图管理：创建/显隐/激活/关闭、截图避让
Core/Win32.cs               P/Invoke 底座：DWM 遮蔽、物理坐标窗口、DPI、显示器
Core/OcrService.cs          OCR 服务（PaddleOCR 优先，自动回退 Windows OCR；小图自动放大）
Core/PaddleOcrEngine.cs     PaddleOCR 本地引擎封装（模型/native 依赖内嵌释放）
Core/TranslateService.cs    翻译：免费接口链（有道/MyMemory/Google/百度/自定义）+ OpenAI 兼容 / DeepL
Views/PinWindow.*           贴图窗口（Setuna 行为核心、图上原位翻译、loading 遮罩）
Views/ExtractPanelWindow.*  提取文字面板（微信式）
Views/TranslateWindow.*     原文译文对照窗口（提取窗口同款 + 译文区，可配置显示原文/译文）
Views/ResultWindow.*        OCR/翻译结果浮窗
Views/SettingsWindow.*      设置窗口
```
